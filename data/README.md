# 教学样例说明

`toy_qa.jsonl` 含 34 条由本项目人工编写的虚构校园问答请求，不来自真实学校政策。

8 份主要材料，每份依次安排原问题、完全重复、改写问题和询问另一事实的近似问题，共 32 条。
另有 1 条更新图书馆规定的请求和 1 条多句证据请求。
没有独立测试集，不能作为论文性能结果。这个刻意安排的请求顺序用于展示缓存行为。

字段：

- `id`：请求唯一 ID。
- `namespace`：缓存用户/应用范围。
- `query` / `context`：算法可见的输入。
- `evidence`：必要证据原文列表，全部保留才记作证据保留。
- `expected`：答案必须含有的片段列表，粗略评分使用。
- `fact_id`：标记请求所问的事实，用于检测错误缓存复用。

后三项仅用于评分，不会传给压缩器或模型。扩展到真实数据时，应说明来源、许可、版本和划分方法。
