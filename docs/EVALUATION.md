# 当前评测协议

评测以完整任务正确性为首要指标，再比较全部模型调用的 token、缓存分项估算费用及端到端耗时。

## 四组与数据

四组分别为原生 Full、Full 加执行检查、插件、插件加执行检查。带检查的两组使用相同合同和真实业务工具。每任务最多六次模型请求，恢复轮次上限三；整个配置最多 144 次尝试。

当前任务包含六个合成长历史情境：明确要求本轮读取日志，或历史读取后当前文件已更新。模型需要从原文提取值、写入本地报告或配置、实际执行检查，最后按约定格式回答。六个情境包含重复模板，不是独立自然任务基准。

setup 使用实际文件工具生成历史；live_updates 在模型调用前更新沙盒文件，历史原文保留旧值。不同组使用独立沙盒与首部标识，不能强制清空服务端缓存。

## 成功与成本

成功同时要求：最终答案正确、文件状态正确、用户指定工具及参数实际执行、检查通过、禁止修改条件满足。只回答正确、只生成报告或只恢复旧原文都不算成功。

每任务的读取、搜索、分页、重复请求、补做、失败和最终回答全部计入。不得通过增加步骤、重置错误状态或删除未完成任务改善分数。真正发生压缩的任务另报告，并匹配同任务的完整历史对照。

费用通过服务商返回的缓存命中/未命中 token 分项核算。配置价格为固定参考值，便于相同口径比较，不能当作账户账单或当前实时价格。未知 usage 单独统计，不视作免费。

## 运行

评测工具需要在仓库目录中运行。

```bash
python -m token_budget_lab.action_experiment --config configs/action_contract_deepseek.json --plan
```

设置本机 `DEEPSEEK_API_KEY` 后执行：

```bash
python -m token_budget_lab.action_experiment --config configs/action_contract_deepseek.json --output local_results/current-run
```

输出目录必须是新目录，不自动重发已执行的付费任务。规范历史、实际文件和完整响应日志只保存在本机输出中。

可以导出该次运行的摘要、全部逐任务结果和最终回答：

```bash
python -c "from token_budget_lab.tool_experiment import export; export('local_results/current-run', 'local_results/current-run/export')"
```

## 已有测量的解释

[当前结果](../results/current/REPORT.md) 来自仓库整理前的最近一次真实运行。本次改动拆出当前插件依赖并移除旧方向，没有新增 API 调用；本地测试验证整理后的协议与工具行为，不能代替重新测量模型质量。

六个合成情境、一次生成运行和事后针对性诊断不足以证明一般任务近乎无损。后续应预先冻结更多独立任务，保留固定实现的对照，按允许准确率差异与成对错误率计算正式验证所需样本量。
