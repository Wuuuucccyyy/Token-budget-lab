# 当前评测协议

评测以完整任务正确性为首要指标，再比较全部模型调用的 token、缓存分项估算费用及端到端耗时。

## 当前三组与数据

v0.10 三组分别为 Full + 数值核验、压缩插件、压缩插件 + 数值核验，全部使用相同执行合同与真实业务工具。Full 与核验插件使用同样的宿主写入规则。每任务最多六次模型请求，恢复轮次上限三；整个配置最多 216 次尝试。两种插件均使用相同的 structured 精准恢复。

当前包含十二个合成长历史情境：六个复用已有诊断，六个新增打乱数组、稀疏编号、超长对象、重复事件、缺失事件及文本末尾目标。模型需要实际读取、提取值、完成授权的写入与检查，并按约定格式回答；不唯一或缺失事件需按用户要求拒答且不写文件。包含重复模板，不是独立自然任务基准。

setup 使用实际文件工具生成历史；live_updates 在模型调用前更新沙盒文件，历史原文保留旧值。不同组使用独立沙盒与首部标识，不能强制清空服务端缓存。

## 成功与成本

成功同时要求：最终答案正确、文件状态正确、用户指定工具及参数实际执行、写后检查通过、禁止修改条件满足。只回答正确、只生成报告或只恢复旧原文都不算成功。禁止写入的情境尝试调用写工具也记约束失败，即使 handler 拒绝而未落盘。

所有条件题的合同只规定同样的本轮读取，写入分支由实际原文决定；不能根据预期唯一/缺失标签提前要求写入。场景编号不暴露缺失或重复标签，标签仅用于执行后的评分与分组。

数值规则来自当前用户措辞中的文件、事件、字段和变换，不读取 answer、report、no_writes 或 live_updates。原值来自实际 handler，本轮缺失或重复必须从文件判断。核验组会收到固定规则提示，提交错误值后可收到原文重算反馈；这是完整接入方案的对照，尚未单独分离提示效果与拒绝干预效果。

每任务的读取、搜索、分页、重复请求、补做、失败和最终回答全部计入。不得通过增加步骤、重置错误状态或删除未完成任务改善分数。真正发生压缩的任务另报告，并匹配同任务的完整历史对照。

费用通过服务商返回的缓存命中/未命中 token 分项核算。配置价格为固定参考值，便于相同口径比较，不能当作账户账单或当前实时价格。未知 usage 单独统计，不视作免费。

## 运行

评测工具需要在仓库目录中运行。

```bash
python -m token_budget_lab.action_experiment --config configs/transform_deepseek.json --plan
```

设置本机 `DEEPSEEK_API_KEY` 后执行：

```bash
python -m token_budget_lab.action_experiment --config configs/transform_deepseek.json --output local_results/current-run
```

输出目录必须是新目录，不自动重发已执行的付费任务。规范历史、实际文件和完整响应日志只保存在本机输出中。

可以导出该次运行的全部任务、请求、执行凭据与成本：

```bash
python scripts/export_current.py --run local_results/current-run --output local_results/current-run/export
```

## 已有测量的解释

[当前结果](../results/current/REPORT.md) 是固定实现、同轮随机顺序的真实对照，156 次请求、36 个任务条件、未知 usage 为零。此前 341 次定位实验消耗单独保留，总账共 497 次请求，旧质量成绩不与本轮混合。调用前保存数据、配置与包源码指纹，运行后没有重发任务。导出脚本从实际 handler 重算全部 20 次写入核验并核对来源；具体轨迹说明只在该轮日志指纹匹配时导出。

Full 通过 12/12，两种插件均通过 11/12。核验插件文件状态正确 12/12，但一题步骤耗尽、没有最终回答；不加核验组同题写入 2.06，实际原文为 206。本轮没有错误写入被核验器拒绝，不将回归测试的故意错误提交计作真实模型纠错次数。

十二个有重复模板的合成情境、一次生成运行和针对性诊断不足以证明一般任务近乎无损。复用情境与新增边界情境分别统计；后续应预先冻结更多独立任务，保留固定实现的对照，按允许准确率差异与成对错误率计算正式验证所需样本量。
