## 同能力对照

- context 相对 full：总 token 减少 84.1%，固定价格估算费用减少 72.6%，检查点质量差 -8.3%。
- context_guarded 相对 full_guarded：总 token 减少 87.7%，固定价格估算费用减少 82.8%，检查点质量差 +0.0%。
- context_guarded 相对 full：总 token 减少 87.0%，固定价格估算费用减少 76.3%，检查点质量差 +4.2%。

Full + 来源核验和插件 + 来源核验使用相同写入合同，单独检验外置/筛选的效果。核验读取真实快照及当前问题，未使用 gold；尚不覆盖任意自然语言推理和写工具。

## 前缀与缓存控制

同一任务内，旧视图与工具定义保持稳定，只有新消息追加。每个实例/组的首部实验标识独立，减少此前请求和跨组缓存预热。没有清空服务端缓存；首请求仅称隔离前缀请求。新 user 任务可能重新选历史，仍需实际 usage 判断收益。

完整任务之外执行 32 次原样首请求重放，不执行业务工具。原请求与重放的缓存分项见 [cache_probes.json](cache_probes.json)。主轮累计 302 次尝试，未知 usage 0 次。

另保留联网受限的启动诊断：1 次尝试、1 次未知 usage。累计研究尝试 303 次；未知项不填零成本。

主轮包含重放的已知 usage 按固定价格重估约 $0.151176，不是账户扣费。价格为核对日 [DeepSeek 官方 Flash 非高峰档](https://api-docs.deepseek.com/quick_start/pricing/)；高峰档两倍。

## 失败与验证边界

共保留 8 个失败检查点。失败原因、实际操作和后续状态见 [失败记录](failure_cases.json)；拒绝写入和检索事件见 [控制事件](controller_events.json)。

每实例仍最多六次模型调用。没有自动重试、调大步骤上限、删除失败或修复中间状态。本轮是固定实现的一次专项试验；八个实例来自四类模板，样本小，不能证明一般场景近乎无损。核验收益不能全部归因于压缩。

真正发生压缩的任务及匹配 Full 对照另见 summary.json 的 compressed_subset；该子集是事后诊断，失败与全部调用仍保留。
