# LangChain 接入验证

v0.13.1 已实现 `TokenBudgetMiddleware`，可在同一个 `create_agent` 图中通过 `TokenBudgetContext.enabled` 切换上下文优化。两组保留相同模型、业务工具、必需操作、数值和条件授权、写入字段范围与十次模型调用上限。文本消息、同步与异步、工具结果配对、来源恢复和严格评分已通过接入测试。

完整真实对照已完成：同一个 LangChain agent 的 Full 与插件均通过 36/36，最终答案全部一致。插件输入输出总 token 减少 85.5%，平均完整任务耗时减少 21.7%，P95 减少 22.7%。本轮 265 次请求均获得 usage，恢复与最终输出完整计入。

固定参考费用减少 84.4%。插件 P95 / Full P95 为 0.773，满足事先声明的不超过 1.15 的目标。两组全部任务均成功，速度比较不需要排除失败任务。三次重复每组均通过 12/12。

插件的 36 个任务全部发生实际压缩，压缩子集通过率为 36/36；相同任务的 Full 也通过 36/36，子集总 token 减少 85.5%。唯一额外恢复请求读取实际来源的 `/events/37/status_code`，返回原文 503，计入上述 133 次调用和任务耗时。

本轮未触发数值或字段权限拒绝；这些拒绝、修正及禁止写入仍判失败的路径通过测试验证。数值规则与字段权限来自宿主当前任务声明，Full 与插件保持一致，没有将未完成或被禁止的操作重新计为成功。

## 实验协议

- 十二个已用于调试的合成模板，各重复三次；Full 与 context_fast 共七十二个任务条件。
- agent 只编译一次，工具和模型实例固定；每个条件使用独立的文件沙盒与会话。
- 开关通过调用上下文设置。Full 保留完整消息并关闭恢复工具；插件保留规范原文，只压缩模型发送视图，直送已声明的短原文字段。
- 必需操作根据当前用户意图声明。条件写入和检查只有在实际唯一来源分支中要求执行；缺失与重复分支只豁免条件操作，不生成执行凭据。
- 工具 schema 的可选字段不自动代表用户授权。模型加入未声明字段时，实际写入不执行，修正和额外请求计入完整任务。
- 答案、文件状态、实际读取、操作顺序和最终回答同时正确才计成功；禁止写入的尝试即使被拦截，也继续判约束失败。
- 全部恢复、纠正、失败调用均核算；耗时包含整个 agent.invoke、工具、归档与审计，单独排除图编译。最多十次模型调用、三轮恢复，总请求上限为 720。
- 价格采用与自带 agent 对照相同的固定参考费率，不代表当前账单。独立随机命名空间减少不同任务共享缓存的影响，仍计入任务内自然缓存。

参数见 [langchain_deepseek.json](../../configs/langchain_deepseek.json)，依赖版本见 [langchain_constraints.txt](../../configs/langchain_constraints.txt)。接入说明与运行例子见 [LANGCHAIN.md](../../docs/LANGCHAIN.md)。

## 已发生的接入诊断

修复前 v0.13.0 的诊断完成了 57/72 个任务条件，并在后续请求中断。已完成的 Full 为 26/28，插件为 29/29。两个 Full 文件状态错误暴露了额外可选字段未受授权范围约束的问题；因此修复版加入明确字段范围与条件完成检查。该诊断覆盖不完整、协议也与修复版不同，不能作为修复版的最终开关比较。

诊断共 213 次请求尝试，其中 212 次有 usage，一次未获得 usage。修复版另有一次 HTTP 402 请求，未获得 usage。两个阶段均未自动重试，日志、来源与全部尝试保留；已有实验的费用另外累计，不与当前任务正确率混合。

HTTP 402 的官方含义是余额不足；恢复余额后执行了上述独立完整对照，未覆盖原日志或将初轮诊断混入新成绩。[DeepSeek 错误码](https://api-docs.deepseek.com/quick_start/error_codes/)

当前实验使用十二个已用于调试的合成模板；三次重复不等于新增独立任务，不能保证开放业务任务始终正确或更快。下一轮需要冻结独立任务，覆盖多文件、多字段、未知证据需求、历史时间窗口及实际业务工具。

## 来源与复核
