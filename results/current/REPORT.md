带执行检查的插件完成全部指定读取，但仍有一个日志任务因证据定位及恢复循环未完成。对比同样带检查的 Full，总 token 减少 83.1%，固定价格费用估算减少 82.8%，P95 增加 28.8%。当前尚未达到完整任务准确率几乎一致或更快的目标。

每任务最多六次模型请求、最多三轮恢复。全部 24 个任务条件和 109 次请求都保留，失败与补做计入成本；插件的六个情境都实际发生压缩，因此压缩子集成功率也是 5/6。

费用使用固定参考价格：每百万 token 的命中输入 0.003 USD、未命中输入 0.15 USD、输出 0.6 USD。四组总估算 0.084132 USD，未知 usage 为 0；不是账户账单或当前实时价格。

数据包含重复模板与受控文件更新，单次合成测量不足以证明一般任务近乎无损。该结果在目录整理前的插件机制上测得；本次仓库整理没有新增付费请求。测量版本为 [ea96cdac](https://github.com/Wuuuucccyyy/Token-budget-lab/commit/ea96cdac9f33ed3a0e92b33e8537a9dcd4eba6a6)，整理后的本地回归测试不计入模型成绩。
